# Qolo Unity source scaffold

Import this `Assets/Qolo/` directory into a Unity 6.3 LTS Universal 3D (URP) project created with Unity Hub. This repository does not contain the generated Unity editor project settings or package lock, because the exact editor patch and packages have not been installed/verified here.

Included source is deliberately limited to a starter ball integrator and elapsed match clock, with small Edit Mode test examples. Enable Unity Test Framework in Package Manager if `TestAssemblies` or NUnit references are not available. The tests are source-only and have not run in this environment.
